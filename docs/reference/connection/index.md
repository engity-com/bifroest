# Connections

Connections represent the way users connect to Bifröst. The [SSH protocol](ssh.md) provides the established interactive transport. [HTTP / HTTPS](http.md) provides jointly supervised TLS listeners, discovery and password, interactive/OIDC-device and public-key authentication APIs sharing verified session selection with SSH. The browser workspace and WebSocket execution protocol remain pending.
