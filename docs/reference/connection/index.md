# Connections

Connections represent the way users connect to Bifröst. Use [SSH](ssh.md) with a standard SSH client, or [HTTPS](http.md) for browser terminals and management access.

For browser setup and use, see [Browser access](../../guides/browser-access.md). Review the [security limits](http/security.md) before enabling it.

## Variants

1. [SSH](ssh.md)
2. [HTTP / HTTPS](http.md)
