# Connections

Connections represent the way users connect to Bifröst. The [SSH protocol](ssh.md) provides the established interactive transport. [HTTP / HTTPS](http.md) now provides jointly supervised TLS listeners, discovery and an initial password login API sharing session selection with SSH. The interactive browser workspace and WebSocket execution protocol remain pending.
