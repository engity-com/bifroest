# Connections

Connections represent the way users connect to Bifröst. Currently, the operational transport is the [SSH protocol](ssh.md). [HTTP / HTTPS](http.md) configuration and shared flow-selection groundwork are available, but the browser listener is not implemented yet.

## Variants

1. [SSH](ssh.md)
2. [HTTP / HTTPS configuration groundwork](http.md)
