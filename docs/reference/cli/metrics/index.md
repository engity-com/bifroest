# `bifroest metrics`

Read operational metrics from the running instance through an authorized [management flow](../management.md). No monitoring port or monitoring bearer token is required.

## Commands

| Command | Purpose |
| --- | --- |
| [`show`](show.md) | Show a snapshot of all available metrics or exact metric families. |

See [Monitoring](../../monitoring.md) for metric names and measurement boundaries.
